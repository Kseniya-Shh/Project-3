# Project-3
Данный проект отражает реальные рабочие процессы в Agile-командах.
Необходимо изучить интервью с заинтересованными лицами и проанализировать его. 
Далее, составить карту пользовательских историй и выделить на ней MVP. 
После, необходимо реализовать прототип с использованием Figma. 
И последняя задача проекта — составить контекстную и логическую диаграммы потоков данных (DFD).
